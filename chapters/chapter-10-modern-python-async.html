1. Type Hints (typing) & Tự Động Hóa API

Python là ngôn ngữ kiểu động (dynamically typed), nhưng việc khai báo Type Hints giúp IDE (VS Code, PyCharm) auto-complete chính xác và là cốt lõi để các thư viện như Django Ninja / Pydantic tự động validate dữ liệu gửi lên từ Frontend.

def func(param: type) -> return_type: Type Annotations
💻 typing_demo.py 
from typing import Optional, List, Dict

# Định nghĩa hàm có Type Hints rõ ràng
def calculate_cart_total(
    items: List[Dict[str, float]], 
    discount_code: Optional[str] = None
) -> float:
    total = sum(item["price"] * item.get("qty", 1.0) for item in items)
    if discount_code == "GIAMGIA20":
        total *= 0.8
    return round(total, 2)

cart = [
    {"price": 150.0, "qty": 2},
    {"price": 49.99, "qty": 1}
]

total_bill = calculate_cart_total(cart, discount_code="GIAMGIA20")
print(f"Tổng tiền thanh toán sau giảm giá: {total_bill} $")

Ứng dụng trong Django Ninja & DRF:

Trong Django Ninja (chuẩn API mới nhất tương thích Django), bạn viết code như sau: 

@api.get("/add")
def add(request, a: int, b: int):
    return {"result": a + b}
Django Ninja sẽ đọc Type Hint int để tự động chuyển chuỗi URL thành số nguyên và tự sinh trang tài liệu tương tác Swagger UI /api/docs hoàn toàn tự động!

2. Dataclasses (@dataclass): Mô Hình Hóa Dữ Liệu Gọn Nhẹ

Không phải dữ liệu nào trong dự án Web cũng cần tạo bảng trong database với models.Model (ví dụ: payload gửi sang cổng thanh toán, response từ OpenWeather API). @dataclass giúp bạn tạo Class chứa dữ liệu mà không cần viết hàm __init__ thủ công.

@dataclass Data Transfer Object (DTO)
💻 dataclass_dto.py 
from dataclasses import dataclass, asdict

@dataclass
class PaymentPayloadDTO:
    order_id: str
    customer_email: str
    amount: int
    currency: str = "VND"

# Tự động có __init__, __repr__, __eq__ mà không cần viết 1 dòng code nào!
payment = PaymentPayloadDTO(
    order_id="VN-98432", 
    customer_email="qtri@example.com", 
    amount=250000
)

print("Đối tượng Dataclass:", payment)
print("Chuyển thành Dictionary gửi qua REST API:")
print(asdict(payment))

3. Async / Await: Nền Tảng Của Django Asynchronous Views

Khi view của bạn cần gọi nhiều API bên ngoài (ví dụ gọi AI Gemini, gửi email, gọi cổng thanh toán), phương thức đồng bộ (Synchronous) sẽ bắt luồng server phải chờ đợi (blocking). async def và await giải phóng luồng để server phục vụ các request khác trong lúc chờ.

async def & await Django 4/5 Async
💻 async_views_concept.py 
import asyncio
import time

# Giả lập gọi microservice bên ngoài mất 1 giây
async def fetch_weather_api(city: str) -> dict:
    print(f"⏳ Bắt đầu gọi API thời tiết cho {city}...")
    await asyncio.sleep(1)  # Non-blocking I/O chờ mạng
    return {"city": city, "temp": 28}

# Asynchronous View trong Django
async def home_dashboard_view():
    start_time = time.time()

    # Gọi đồng thời 2 API cùng lúc mà không bị chờ cộng dồn!
    task1 = fetch_weather_api("Hà Nội")
    task2 = fetch_weather_api("TP. Hồ Chí Minh")
    
    results = await asyncio.gather(task1, task2)
    elapsed = time.time() - start_time

    print(f"✅ Hoàn thành 2 API chỉ trong: {elapsed:.2f} giây!")
    print("Kết quả thời tiết:", results)

# Chạy event loop:
asyncio.run(home_dashboard_view())

Ứng dụng trong Django 5.x:

Django hiện tại hỗ trợ đầy đủ async def my_view(request): và Async ORM như await Post.objects.afirst() hoặc async for post in Post.objects.all():. Nhờ đó, hiệu năng I/O bound của Django có thể tăng gấp 3-5 lần khi xử lý đồng thời nhiều kết nối websocket hoặc microservices.
