Context Managers, Generators & Xử Lý Dữ Liệu Tối Ưu

Lập trình Web quy mô lớn đòi hỏi kiểm soát tài nguyên nghiêm ngặt: đảm bảo đóng mở kết nối cơ sở dữ liệu an toàn (Database Transactions) và xuất dữ liệu hàng trăm ngàn dòng mà không làm sập server vì tràn bộ nhớ RAM.

1. Câu Lệnh with & Giao Thức Context Manager (__enter__, __exit__)

Bất cứ khi nào bạn thấy câu lệnh with something:, Python đang âm thầm gọi phương thức __enter__ khi bắt đầu khối và __exit__ khi kết thúc khối (kể cả khi bên trong bị văng lỗi).

with ContextManager() as resource Safe Resource Management
💻 context_manager_protocol.py 
class DatabaseLock:
    def __init__(self, resource_name):
        self.resource_name = resource_name

    def __enter__(self):
        print(f"🔒 [1. ENTER] Khóa tài nguyên '{self.resource_name}' độc quyền")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print(f"🔓 [3. EXIT] Giải phóng khóa cho '{self.resource_name}'")
        if exc_type:
            print(f"   ⚠️ Phát hiện ngoại lệ trong khối with: {exc_val}")
            # Trả về False để Python tiếp tục ném lỗi lên trên
            return False
        return True

# Sử dụng câu lệnh with:
with DatabaseLock("order_table"):
    print("   ⚡ [2. EXECUTE] Đang xử lý tính tiền đơn hàng...")

2. Giải Mã transaction.atomic() Trong Django

Trong thanh toán online, bạn cần: (1) Trừ tiền tài khoản người gửi & (2) Cộng tiền tài khoản người nhận. Nếu bước 2 bị lỗi mất điện, bước 1 bắt buộc phải được Rollback (hoàn tác)!

with transaction.atomic(): Database Consistency
💻 transaction_demo.py 
from contextlib import contextmanager

# Tự mô phỏng cách Django xây dựng transaction.atomic()
@contextmanager
def atomic_transaction():
    print("BEGIN TRANSACTION; (Bắt đầu chuỗi thao tác CSDL)")
    try:
        yield  # Nhường quyền cho code bên trong khối with chạy
        print("COMMIT; (✅ Toàn bộ thao tác thành công, chốt lưu CSDL)")
    except Exception as e:
        print(f"ROLLBACK; (❌ Có lỗi: '{e}' -> Hoàn tác mọi thay đổi về số dư ban đầu!)")
        raise

# Giả lập chuyển tiền bị lỗi ở giữa:
try:
    with atomic_transaction():
        print(" -> Bước 1: Trừ 500,000 đ tài khoản A")
        # Giả lập lỗi ném ra từ cổng thanh toán
        raise ConnectionError("Mất kết nối với ngân hàng B!")
        print(" -> Bước 2: Cộng 500,000 đ tài khoản B")
except ConnectionError:
    print("Thông báo: Tiền của bạn không bị mất.")

Ứng dụng trực tiếp trong Django:

Trong views.py, bạn chỉ cần viết: with transaction.atomic(): user.save(); profile.save(); order.save(). Nếu có bất kỳ dòng nào bị lỗi, Django sẽ hoàn tác toàn bộ thay đổi trong database tự động mà bạn không cần phải viết code dọn dẹp thủ công.

3. Generators, yield & Xuất Dữ Liệu Lớn (Streaming)

Một hàm chứa từ khóa yield sẽ trở thành một Generator. Thay vì tính toán toàn bộ danh sách rồi giữ trong RAM, nó chỉ sinh ra 1 phần tử tại một thời điểm (Lazy Evaluation).

yield & StreamingHttpResponse Memory Saver
💻 stream_csv_generator.py 
import sys

# ❌ Cách thường: Tạo mảng 500,000 số trong RAM
full_list = [i for i in range(500_000)]
print(f"Dung lượng RAM của List: {sys.getsizeof(full_list):,} bytes")

# ✅ Cách dùng Generator: Sinh từng dòng khi cần
def export_large_csv_stream():
    yield "id,username,email\n"
    for i in range(1, 4):
        # Mỗi lần chỉ sinh 1 dòng CSV
        yield f"{i},user_{i},user_{i}@example.com\n"

gen = export_large_csv_stream()
print(f"Dung lượng RAM của Generator: {sys.getsizeof(gen)} bytes (Siêu nhẹ!)")

print("\nNội dung stream tải về trình duyệt:")
for chunk in gen:
    print(chunk, end="")

Ứng dụng trực tiếp trong Django:

Khi người dùng yêu cầu xuất file Excel báo cáo gồm 100,000 đơn hàng, nếu dùng HttpResponse thông thường, server sẽ nạp toàn bộ vào RAM gây tràn bộ nhớ (Out of Memory) làm restart app. Thay vào đó, Django cung cấp StreamingHttpResponse(export_generator(), content_type="text/csv") kết hợp với QuerySet.iterator() để truyền dữ liệu thẳng xuống client từng chunk một!

4. pathlib.Path: Chuẩn Đường Dẫn Hiện Đại Trong settings.py

Từ Django 3.1 trở lên, toàn bộ hệ thống đường dẫn chuyển sang dùng thư viện pathlib chuẩn Python 3 thay thế hoàn toàn cho os.path.join() cồng kềnh.

from pathlib import Path; BASE_DIR / 'subfolder' Modern Path API
💻 pathlib_django_settings.py 
from pathlib import Path

# Cách định nghĩa BASE_DIR chuẩn trong settings.py:
BASE_DIR = Path(__file__).resolve().parent.parent

# Toán tử / thanh lịch để nối đường dẫn:
TEMPLATES_DIR = BASE_DIR / "templates"
STATIC_DIR = BASE_DIR / "static"
MEDIA_ROOT = BASE_DIR / "media"
DATABASE_FILE = BASE_DIR / "db.sqlite3"

print("Thư mục gốc BASE_DIR:", BASE_DIR)
print("Thư mục Templates:", TEMPLATES_DIR)
print("File SQLite DB:", DATABASE_FILE)
print("Đuôi mở rộng của database:", DATABASE_FILE.suffix)
