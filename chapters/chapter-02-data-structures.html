Cấu Trúc Dữ Liệu Nâng Cao & Tối Ưu Xử Lý

Trong Django, mọi dữ liệu nhận từ người dùng (`request.GET`, `request.POST`), dữ liệu đưa vào Template (`context`) hay trích xuất từ database (`QuerySet`) đều xoay quanh các cấu trúc Dictionary, List, Tuple và Set của Python.

Mức độ: Cốt lõi (Crucial) Tần suất dùng: Liên tục mọi file Thời gian đọc: 15 phút
#

1. Dictionary: .get() & .setdefault() An Toàn

Truy cập phần tử từ điển theo cách truyền thống data['key'] sẽ văng ra KeyError nếu key không tồn tại, khiến web server trả về mã lỗi 500! Dưới đây là cách chuẩn chỉ để trích xuất dữ liệu HTTP request trong Django.

dict.get(key, default=None) Data Extraction
Trích xuất giá trị nếu key có trong từ điển; nếu không có, trả về giá trị mặc định thay vì làm crash chương trình.
💻 dict_extraction.py 
# Giả lập request.GET nhận từ URL: /products?page=2
request_get = {"page": "2"}

# ❌ Cách nguy hiểm:
# sort_order = request_get["sort"] -> Bị lỗi KeyError! Crash app!

# ✅ Cách chuẩn Django: Dùng .get()
page_number = request_get.get("page", "1")
sort_order = request_get.get("sort", "created_at")
category = request_get.get("category") # mặc định là None

print(f"Trang hiện tại: {page_number}")
print(f"Tiêu chí sắp xếp: {sort_order}")
print(f"Danh mục: {category}")

# setdefault(): Thêm key nếu chưa có, lấy key nếu đã có
session_cart = {}
session_cart.setdefault("items", []).append({"id": 101, "qty": 1})
print("Giỏ hàng:", session_cart)
Terminal Output Đối Chiếu stdout 
$ python dict_extraction.py
Trang hiện tại: 2
Tiêu chí sắp xếp: created_at
Danh mục: None
Giỏ hàng: {'items': [{'id': 101, 'qty': 1}]}
🎯

Ứng dụng trực tiếp trong Django:

Trong views.py, bạn sẽ liên tục viết: keyword = request.GET.get('q', '') hoặc email = request.POST.get('email'). Không bao giờ dùng ngoặc vuông request.POST['email'] vì nếu form thiếu trường đó người dùng sẽ thấy trang báo lỗi 500 khó chịu.

2. List & Dictionary Comprehensions

Viết code gọn gàng, tốc độ thực thi cao hơn vòng lặp for thông thường khi cần biến đổi dữ liệu trả về từ Database QuerySet.

[expr for item in iterable if condition] Transform & Filter
Tạo danh sách hoặc từ điển mới chỉ bằng một biểu thức ngắn gọn, thanh lịch.
💻 comprehensions_demo.py 
# Giả lập danh sách bài viết lấy từ Django ORM: Post.objects.all()
posts = [
    {"id": 1, "title": "Học Python Cơ Bản", "is_published": True},
    {"id": 2, "title": "Django Models Toàn Tập", "is_published": False},
    {"id": 3, "title": "Triển Khai VPS Nginx", "is_published": True},
]

# 1. List Comprehension: Lọc và lấy danh sách tiêu đề bài đã xuất bản
published_titles = [p["title"] for p in posts if p["is_published"]]
print("Tiêu đề đã xuất bản:", published_titles)

# 2. Dict Comprehension: Tạo bảng tra cứu nhanh theo ID (ID -> Title)
post_lookup = {p["id"]: p["title"] for p in posts}
print("Tra cứu nhanh Post ID=3:", post_lookup.get(3))
Terminal Output Đối Chiếu stdout 
$ python comprehensions_demo.py
Tiêu đề đã xuất bản: ['Học Python Cơ Bản', 'Triển Khai VPS Nginx']
Tra cứu nhanh Post ID=3: Triển Khai VPS Nginx
🎯

Ứng dụng trực tiếp trong Django:

Thường dùng khi chuẩn bị context gửi sang Template hoặc render JSON API: user_ids = [user.id for user in queryset] hoặc chuẩn bị dữ liệu cho biểu đồ Chart.js thống kê doanh thu.

3. Tuples & Cặp Giá Trị trong Model Choices

Tuple là cấu trúc bất biến (immutable). Django sử dụng tuple of tuples hoặc models.TextChoices để tạo dropdown danh sách chọn trong form và admin.

Tuple Unpacking & Choices Django Models
Mỗi mục trong Choices luôn là một cặp tuple gồm: (Giá_trị_lưu_vào_Database, Tên_hiển_thị_trên_Giao_diện).
💻 model_choices_pattern.py 
# Định nghĩa danh sách trạng thái đơn hàng (Django Model Choices)
ORDER_STATUS_CHOICES = (
    ("PENDING", "Chờ xác nhận"),
    ("SHIPPING", "Đang giao hàng"),
    ("COMPLETED", "Đã hoàn thành"),
    ("CANCELLED", "Đã hủy"),
)

# Tuple Unpacking trong vòng lặp
print("Danh sách hiển thị trong dropdown chọn lọc:")
for db_code, label in ORDER_STATUS_CHOICES:
    print(f" [Option] Mã DB: {db_code:<10} -> Nhãn: {label}")

# Tuple Unpacking hoán đổi giá trị mà không cần biến tạm
a, b = 100, 200
a, b = b, a
print(f"Sau khi hoán đổi: a={a}, b={b}")
Terminal Output Đối Chiếu stdout 
$ python model_choices_pattern.py
Danh sách hiển thị trong dropdown chọn lọc:
 [Option] Mã DB: PENDING    -> Nhãn: Chờ xác nhận
 [Option] Mã DB: SHIPPING   -> Nhãn: Đang giao hàng
 [Option] Mã DB: COMPLETED  -> Nhãn: Đã hoàn thành
 [Option] Mã DB: CANCELLED  -> Nhãn: Đã hủy
Sau khi hoán đổi: a=200, b=100
🎯

Ứng dụng trực tiếp trong Django:

Trong models.py: status = models.CharField(max_length=20, choices=ORDER_STATUS_CHOICES, default='PENDING'). Django sẽ tự động sinh hàm order.get_status_display() trả về nhãn tiếng Việt tương ứng.

4. Set Operations & Kiểm Tra Quyền Hạn (Permissions)

Tập hợp (Set) chứa các phần tử duy nhất (unique) và hỗ trợ các phép toán giao (&), hợp (|), trừ (-) với độ phức tạp tìm kiếm cực nhanh O(1).

set.intersection() & issubset() Fast Membership Test
💻 permissions_check.py 
# Quyền mà user hiện tại đang có (lấy từ các nhóm và vai trò)
user_permissions = {"blog.view_post", "blog.add_post"}

# Quyền tối thiểu yêu cầu để xóa bài viết
required_for_delete = {"blog.delete_post"}

# Kiểm tra xem user có quyền xóa không
can_delete = bool(user_permissions & required_for_delete)
print("User có thể xóa bài viết không?", can_delete)

# Kiểm tra yêu cầu nhiều quyền cùng lúc:
required_all = {"blog.view_post", "blog.add_post"}
has_all = required_all.issubset(user_permissions)
print("User có đủ mọi quyền yêu cầu không?", has_all)
Terminal Output Đối Chiếu stdout 
$ python permissions_check.py
User có thể xóa bài viết không? False
User có đủ mọi quyền yêu cầu không? True
🎯

Ứng dụng trực tiếp trong Django:

Hệ thống bảo mật django.contrib.auth lưu toàn bộ permission codenames của user dưới dạng Python Set trong bộ nhớ cache để hàm user.has_perm('app.change_item') chạy tức thì không cần query lại database nhiều lần.

5. F-strings: Format URL, Slugs & Đường Dẫn Upload

F-strings (Formatted String Literals) là chuẩn format chuỗi hiện đại và nhanh nhất của Python từ phiên bản 3.6 trở đi.

f"strings with {expression}" Formatting
💻 fstrings_django_urls.py 
from datetime import datetime

user_id = 42
username = "qtri"
slug = "django-deep-dive"
now = datetime(2026, 10, 16)

# 1. Tạo canonical URL cho bài viết
canonical_url = f"/articles/{now.year}/{now.month:02d}/{slug}/"
print("URL bài viết:", canonical_url)

# 2. Tạo đường dẫn lưu ảnh tải lên theo user và ngày tháng
avatar_filename = "profile.png"
upload_path = f"uploads/users/{user_id}_{username}/{now:%Y/%m}/{avatar_filename}"
print("Đường dẫn lưu file trên S3 / Server:", upload_path)
Terminal Output Đối Chiếu stdout 
$ python fstrings_django_urls.py
URL bài viết: /articles/2026/10/django-deep-dive/
Đường dẫn lưu file trên S3 / Server: uploads/users/42_qtri/2026/10/profile.png
🎯

Ứng dụng trực tiếp trong Django:

Hàm get_absolute_url() trên Model hoặc tham số upload_to trên models.FileField đều dùng f-strings để sinh cấu trúc thư mục lưu file gọn gàng, tránh việc trùng tên ảnh của người dùng.
